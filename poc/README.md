## 关键技术点（也是踩坑记录）

1. **表单式 KV 布局**：标签右对齐紧贴值（间隙 ~1.5pt），阅读顺序上值可能出现在标签之前。解法：冒号后缀识别 + 同行向右小间隙吸附（`extract_key_values`）。
2. **多标题同行**（并排面板）：`钻井液性能` 与 `当日材料` y0 仅差 **0.05pt**，精确相等分组失效。解法：容差分组（±3pt）+ 配置化 x 边界。
3. **内容归属算法**：token 归属"最近的上方标题"，同级多标题用 YAML 提示的 x 边界或标题间隙中点切分；同排但位于标题左侧的内容跳过该标题向上归属。
4. **列检测**：无表格线，用 x 方向占用直方图找空白谷（≥5pt）作为列边界（`detect_column_bands`），对左对齐标签列、居中数值列均有效。
5. **原文保真**：段落仅做"去折行拼接"（行尾无句末标点则直接续接），不做任何字符级改写；KV 原始串保留在 `source.kv_raw`。

## 已知限制（POC 边界内，属预期）

1. **版面提示为模板级配置**：`section_xbands` / `same_row_boundaries` 中的 x 数值（如 400/296）绑定当前模板。模板规则本就设计为按模板配置（field_rules.yaml），换模板需重配——这正是 §4.4 规则可配置原则的体现。
2. **非 MVP 区域存在噪声归属**：页1 中部的小面板（循环数据/钻具组合/井数据等）之间有少量串列，未影响 MVP 字段；页2 材料追踪大表、页3 数量日报未纳入本次映射范围。
3. **span 粘连风险**：PDF 内部把标签和值排进同一 span 时（如某处 `液量/冲19.6L/stk`），词级拆分无法还原。MVP 目标区域未出现，后续可用字符级 bbox 切分兜底。
4. **置信度为占位规则**：当前 exact=0.99 / numeric=0.97 / derive=0.9 为占位，阈值待按 §11.2 用误差统计确定。
